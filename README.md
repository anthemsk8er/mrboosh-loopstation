# MrBoosh Loopstation

Loop station de 5 pistas para beatbox. DSP en Rust compilado a WebAssembly, dentro de un
AudioWorklet. Estética de hardware real, UI en español/inglés, undo, fusión de pistas por
arrastre, 4 efectos por pista y calibración de latencia (automática y manual).

Este repo es sólo el **build estático** que sirve GitHub Pages; el proyecto se desarrolla en otro lado.
